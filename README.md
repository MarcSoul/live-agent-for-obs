# Live Agent

Asistente de producción para OBS Studio. Prepara escenas, comprueba fuentes y opera el directo en lenguaje natural.

## Primer objetivo

En macOS, pedir «Prepárame una entrevista con tres cámaras y audio de mesa» y obtener un montaje verificable en el previo de OBS Studio, con un rótulo editable y una receta reutilizable.

El proyecto está en fase de diseño. La [arquitectura y el backlog](docs/development.md) definen el primer prototipo.
